# Pengembaraan Ilmu Pendidikan Jasmani Tahun 2 — Mari Melompat

## Fail
- `index.html` — aplikasi lengkap; HTML, CSS dan JavaScript berada dalam satu fail.
- `README.md` — panduan penggunaan dan penerbitan.
- `soalan-dan-skema.md` — 25 soalan, jawapan betul dan penerangan untuk semakan guru.

## Cara guna
1. Muat turun `index.html`.
2. Buka fail itu menggunakan Chrome, Edge, Firefox atau Safari versi terkini.
3. Masukkan nama murid dan tekan **Mula Pembelajaran**.
4. Lengkapkan objektif, nota, video/pautan YouTube, permainan, dan kuiz 25 soalan.
5. Pada keputusan, gunakan **Cetak / Simpan PDF** untuk mencetak atau memilih “Save as PDF”.

Aplikasi berfungsi tanpa pelayan untuk nota, permainan, kuiz, pemarkahan, audio maklum balas dan cetakan. Pautan YouTube memerlukan sambungan Internet. Suara menggunakan Speech Synthesis Bahasa Melayu jika tersedia pada peranti; bunyi ringkas dijana oleh pelayar. Kemajuan disimpan menggunakan `localStorage` pada pelayar/peranti yang sama. Butang “Sambung kemajuan” memuatkan kemajuan tersimpan. Data tidak dihantar ke pelayan.

## Kurikulum yang digunakan
- **Tema/bidang:** Pergerakan Asas — Kemahiran Lokomotor.
- **Unit RPT:** Unit 2 — Mari Bersenam.
- **Tajuk kecil:** Mari Melompat (RPT Tahun 2 2026 yang ditemui menyenaraikan BT m/s 10).
- **SK 1.2:** Melakukan pelbagai pergerakan lokomotor.
- **SP 1.2.2:** Melompat pada satu jarak, mendarat dengan kedua-dua belah kaki dan lutut difleksi.
- **SK 2.2:** Mengaplikasikan konsep pergerakan semasa melakukan pergerakan lokomotor dan bukan lokomotor.
- **SP 2.2.2:** Menerangkan kepentingan fleksi dalam pergerakan lokomotor dan bukan lokomotor.
- **SK 5.2:** Menunjukkan keyakinan dan tanggungjawab kendiri semasa melakukan aktiviti fizikal.
- **SP 5.2.2:** Menerima cabaran dan seronok semasa melakukan aktiviti.

RPT yang ditemui ialah salinan RPT Tahun 2 2026 yang dikongsi dalam talian, bukan RPT khusus sekolah pengguna. Sahkan turutan unit/minggu dengan RPT sekolah sebelum digunakan secara rasmi. Kandungan DSKP disemak silang dengan salinan DSKP KSSR Semakan 2017 Tahun 2 dan laman sumber digital panitia PJPK yang memautkan DSKP dan buku teks digital.

## Terbitkan dengan GitHub Pages
1. Log masuk ke GitHub dan cipta repository baharu, contohnya `pj-tahun-2-mari-melompat`.
2. Muat naik `index.html`, `README.md`, dan `soalan-dan-skema.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, kemudian tekan **Save**.
6. Tunggu proses penerbitan selesai. URL akan dipaparkan pada halaman Pages GitHub. Jangan anggap aplikasi telah diterbitkan sehingga GitHub memaparkan URL tersebut.
